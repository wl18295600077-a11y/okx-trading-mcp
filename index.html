常见问题

我是新手，能直接用吗？

可以。双击 install.bat，按向导填 API Key，然后复制一段配置到你的 MCP 客户端即可。全程 2 分钟，不需要写任何代码。

我的 API Key 安全吗？

凭证只保存在你自己电脑的 .env 文件里，交易请求直接发往 OKX 官方 API，不经过任何第三方服务器。建议创建 API Key 时开启 IP 白名单，并只勾选「交易」权限（切勿勾选提现权限）。

支持哪些客户端？

任何支持 MCP 协议的客户端：Claude Desktop、Cursor、Cherry Studio、Hermes、Windsurf、Claude Code 等。配置方式完全一样。

和 OKX 的 API 直连有什么区别？

API 直连需要你写代码、处理签名、踩双向持仓/张数取整/条件单等坑。这个产品把这些全部封装好，让 AI 直接调用，你只需要用自然语言描述交易意图。

能保证盈利吗？

不能，任何声称保证盈利的都是骗局。合约交易风险极高，本工具只负责「执行你的交易指令」，策略和风控由你自己决定。请在风险承受范围内交易。
